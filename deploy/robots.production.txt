# solsticellp.com - the live site. Crawlable, deliberately.
#
# The staging host serves deploy/robots.staging.txt instead, which is
# Disallow: /. Which file a build gets is the ROBOTS_SRC build arg in
# deploy/web.Dockerfile - production must never inherit the staging one, and
# that mistake is exactly what this split exists to prevent.

User-agent: *
Allow: /

# /admin, not /#admin: "#" opens a comment in robots.txt, so the old line read
# as a bare "Disallow: /" - the whole site. It survived only because an equally
# specific "Allow: /" outranks it in Google's least-restrictive tie-break.
# The admin is a real path now. This is belt and braces either way: it is also
# served with X-Robots-Tag: noindex and sits behind a JWT, because robots.txt
# is a request, not a lock.
Disallow: /admin
